Plan Bob's **1.1** release. Do not write implementation code yet. Investigate the codebase first, then

## Context
Bob is at **1.0** (a private, local first AI: local inference, an agent loop, a coding agent, memory,
voice, vision, one Python engine, cross platform). The current state and the full version plan are in
[ROADMAP.md](../../ROADMAP.md). Read the 1.1 section there first, then this prompt refines it. Project
rules, layout, and my working preferences are already in the repo's CLAUDE.md and your memory (honor
them, especially: no auto commit, no em or en dashes in prose, and the three layer tool/plugin placement
rule). Versioning: semver, and every release must stay reproducible through `versions.lock`.

## Scope of 1.1 (three items, one theme: a new machine goes from nothing to a working Bob, and a normal
install never trips over Docker)

1. **One command install.** A hosted install script replacing the clone plus two script dance with a
   single line per OS: `curl -fsSL <domain> | sh` on Linux and macOS, `irm <domain>/install.ps1 | iex` on
   Windows. It clones with submodules, runs the prereq and setup steps, verifies against `versions.lock`,
   and is idempotent on re run. Linux and Windows ship in 1.1; macOS waits for 2.0.

2. **A Docker-free default install.** Nothing in Bob's core needs Docker; only three optional add-on
   services do (SearXNG, n8n, Langfuse), and setup does not install Docker, so a default install cannot
   reach them today. The locked direction:
   - **SearXNG** (private search): run native in a venv, out of the box.
   - **n8n** (workflow builder): run native on the Node toolchain setup already installs.
   - **Langfuse** (observability): keep it as an explicit Docker opt in. When the user opts in, make Docker
     painless: a guided Docker install through the same package manager seam setup already uses, then a
     single command that brings up Langfuse and its Postgres from the pinned compose file, with clear
     steps to reach the dashboard.
   - For the Docker averse, point Bob's existing OpenTelemetry traces at a lighter native sink instead of
     Langfuse.
   - Goal: a normal install never trips over Docker; Docker becomes a choice the user is walked through
     only for the Langfuse dashboard.

3. **Onboarding and entry clarity.** Finish the first run polish (the "it does not know me yet" case) and
   make the single entry point unmistakable for a new user.

## Decisions already made (do not re-litigate; plan within them)
- Default install is 100% Docker-free. SearXNG and n8n go native; Langfuse is Docker-only and opt-in.
- Web search already degrades to a direct provider (DuckDuckGo) when SearXNG is down
  (`agent.webSearchFallback`, default on), so search never hard-requires Docker. Keep that fallback.
- The Windows install one liner using PowerShell (`irm | iex`) is an OS-shell bootstrap, not a return of
  the retired PowerShell harness. That is fine, mirror how `install_prereqs.bat` bootstraps today.
- macOS is out of scope for 1.1 (it arrives in 2.0).
